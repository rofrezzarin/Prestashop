EDITOR DE IMAGENS — VERSÃO 1.0.14

COMO ATUALIZAR
1. Abra o ZIP. Ele contém a pasta editor-de-imagens completa.
2. Copie essa pasta para /wp-content/plugins/printway/ pelo FTP,
   substituindo os arquivos da pasta editor-de-imagens existente.
3. Abra a página do editor e confirme “versão 1.0.14” no topo.
   Se aparecer uma versão anterior, limpe o cache da página na hospedagem/
   WordPress e recarregue com Ctrl + F5.
4. Clique em Carregar e selecione seu PNG ou JPEG.

ARQUIVOS DO APLICATIVO
editor-de-imagens/dtf-uv-editor.php
editor-de-imagens/views/editor.php
editor-de-imagens/assets/js/editor.js
editor-de-imagens/assets/css/editor.css

CAUSA CONFIRMADA E CORREÇÃO
O WordPress executava os exemplos de shortcode dentro da Ajuda, criando
mais dois editores ocultos. A imagem era desenhada no canvas de um deles.
Os exemplos agora permanecem texto. Cada editor usa seus próprios controles
mesmo quando o HTML antigo contém outros editores aninhados. O carregamento
passa por um único fluxo, integrado aos objetos e ao histórico.
O CSS foi mantido, incluindo os quadrinhos que indicam transparência.
As versões dos arquivos CSS/JS incluem um identificador do conteúdo para
renovar o cache quando os arquivos mudarem.

VALIDAÇÃO
A falha foi reproduzida no navegador na página pública: após selecionar
um PNG, o estado “Imagem carregada” era atualizado no editor oculto.
A correção passou em 8 testes locais usando DOM jsdom e canvas nativo Skia,
com decodificação real de PNG/JPEG e conferência dos pixels. Incluídos:
HTML capturado do site, exemplos da Ajuda, arquivo repetido, arrastar/colar,
abas, Ajuda, Desfazer/Refazer, erro de arquivo inválido, múltiplas instâncias
independentes e inicialização tardia pelo Elementor.
Sintaxe JavaScript verificada pelo Node; PHP verificado pelo parser PHP.
A instalação destes arquivos no servidor é feita com os passos acima.
