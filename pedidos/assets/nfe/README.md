# Validação estrutural da NF-e

Os arquivos em `schemas/PL_010_V1.30` foram obtidos do projeto aberto
[`nfephp-org/sped-nfe`](https://github.com/nfephp-org/sped-nfe), que mantém os
esquemas de NF-e utilizados pelo validador PHP deste plugin.

O arquivo `NFEPHP-LICENSE.md` preserva a licença distribuída pelo projeto.

Esta validação confere o leiaute XML. Ela não substitui a assinatura com
certificado ICP-Brasil nem a autorização de uso devolvida pela SEFAZ.
