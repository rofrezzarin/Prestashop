SERVIÇO DE IA DO BOTÃO MÁGICO
================================

Requisito: VPS com Docker Compose e acesso SSH.

1. Copie esta pasta "ia-remocao" para a VPS.
2. Dentro dela, execute:

   docker compose up -d

3. O WordPress acessará o serviço privadamente em:

   http://127.0.0.1:7000/api/remove

A porta foi vinculada somente ao endereço local da VPS. Não a exponha
diretamente à internet. O próprio WordPress valida o arquivo e encaminha a
imagem para o contêiner.

Na primeira execução, o rembg baixa automaticamente o modelo
"birefnet-general". Essa primeira remoção pode demorar mais; as seguintes
reutilizam o modelo salvo no volume "rembg_models".

Se o contêiner estiver em outro servidor privado, adicione ao wp-config.php,
antes da linha que encerra a edição:

define( 'DTF_UV_REMBG_ENDPOINT', 'http://IP-PRIVADO:7000/api/remove' );

O servidor PHP do WordPress precisa ter a extensão cURL habilitada.

Diagnóstico:

   docker compose ps
   docker compose logs --tail=100 rembg

O editor solicita explicitamente o modelo birefnet-general e a limpeza de
contaminação de cor nas bordas. Nenhuma imagem é apagada do projeto quando a
IA falha; a troca dos objetos acontece somente após uma resposta PNG válida.
